# PM 项目资料

按项目和功能查看原型与 PRD。

## 目录

- `元游猫/APP2.0/`：原型与对应 PRD v1.4。
- `5E/`：暂无功能资料。
- `assets/catalog.js`：项目、功能与文件路径。
- 根目录与项目目录的 `index.html`：资料入口；样式和交互共用 `assets/`。

## 迭代方式

在对应项目的功能目录中修改原型与 PRD，更新 `assets/catalog.js` 的版本和状态。每个功能直接提供原型、PRD 入口，不添加使用说明或资料迁移记录。文件历史由 Git 保存。

页面目录以根 `index.html` 为模板；项目目录入口仅替换资源相对路径与 `data-initial-project`，不经过跳转页。原型按钮直接指向原型 HTML 文件。

PRD v1.4 的原文和状态保留：待用户确认，不进入研发。资料展示不代表研发或线上状态。
