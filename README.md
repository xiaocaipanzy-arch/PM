# 项目查看页

一个项目链接，在同一页面切换查看当前功能的原型和 PRD。

- `?project=yuanyoumao&feature=app2&view=prototype`：元游猫 APP2.0 原型。
- `?project=yuanyoumao&feature=app2&view=prd`：同一功能的 PRD。
- `?project=5e`：5E 示例项目，暂无资料。

项目和历史版本来源收在“更多资料”。原型在当前页嵌入显示，切换 PRD 后返回原型保留其已加载状态。分享链接定位当前项目、功能与查看类型。

内容仍按项目、功能目录迭代，元数据由 `assets/catalog.js` 维护。原型与 PRD 原文保持不变。该版本先供本地确认，尚未发布。
