## 目录约定

```text
元游猫/
  APP2.0/
    index.html
    元游猫_APP2.0_A方案_全链路产品原型_v1.4.html
5E/
```

- 元游猫内容归入 `元游猫/`，5E 内容归入 `5E/`；各项目下按功能建立子目录。
- 后续修改在对应项目、功能的原型文件中迭代，保持预览入口稳定；历史由 Git 提交记录保存。
- 根目录仅放项目导航和仓库说明；项目事实与业务资料按项目隔离。
- 新功能使用功能分支，检查原型后合入 `main`；Pages 从 `main` 根目录发布。
- 仓库与预览为公开内容。只提交确认可公开的原型及必要资源，不上传凭据、个人数据、内部 PRD、压缩包或完整知识库。
