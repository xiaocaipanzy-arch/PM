# PM 项目资料站

免登录浏览已公开的项目原型、说明文档与迭代记录。

## 查看入口

- [项目资料站](https://xiaocaipanzy-arch.github.io/PM/)
- [元游猫](https://xiaocaipanzy-arch.github.io/PM/?project=yuanyoumao)
- [5E](https://xiaocaipanzy-arch.github.io/PM/?project=5e)：暂无公开资料。

## 目录约定

```text
index.html             项目资料站入口
assets/                页面样式、交互与公开资料目录
  catalog.js           项目、功能、文件元数据
元游猫/
  APP2.0/              原型、使用说明与更新记录
5E/                    后续按功能加入公开资料
```

元游猫资料归入 `元游猫/`，5E 资料归入 `5E/`；项目下按功能建立子目录。修改在对应项目与功能中迭代，保持原型入口稳定，历史由 Git 保存。

## 后续迭代

1. 在对应项目、功能目录添加或修改文件。
2. 在 `assets/catalog.js` 的对应项目和功能下登记文件路径、资料类型、版本、日期与说明。文件不会自动扫描入站。
3. 新功能使用功能分支。检查链接、原型和窄屏显示后合入 `main`。
4. GitHub Pages 从 `main` 根目录发布，分享网址保持不变。

资料类型支持交互原型、文档说明和更新记录。Markdown 文档可在资料站内阅读；新增其他格式前补充相应预览或下载方式。没有资料的项目显示空状态，不展示虚构文件。

## 公开范围

仓库和网站均公开。只纳入确认可公开的资料，不上传凭据、个人数据、内部 PRD、压缩包或完整知识库。项目事实、文档状态和线上状态分别记录。
