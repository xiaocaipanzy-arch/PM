# 项目内容与查看页

入口分两层：项目内容聚合页 → 功能或资料查看页。

## 链接

- `?project=5e`：5E 项目内容聚合页。
- `?project=yuanyoumao`：元游猫项目内容聚合页。
- `?project=项目ID&feature=功能ID&resource=资料ID`：定位具体资料，同页切换该功能的原型、PRD 或报告。

聚合页按登记内容展示功能原型、PRD、调研报告、历史资料等入口，支持搜索与类型筛选。没有资料不生成示例文件。更多项目与 Git 版本来源放在“更多资料”。

## 跨项目上传与展示约定

- 哪个项目聊天产生的交付物，就归入 PM 仓库对应项目目录：5EPlay → `5E/`，元游猫 → `元游猫/`。
- 项目内按功能、调研或交付主题组织，原型、PRD、报告及必要附件在对应主题内维护。
- 资料上传由对应项目会话负责。本 UI 会话只维护页面、资源类型支持和目录读取，不替项目选择公开内容。
- 上传时在 `assets/catalog.js` 的对应项目 `features` 中登记主题及其 `resources`。新增主题会出现在项目聚合页，无需手工新增页面卡片。
- 资源保留唯一 `id`、`title`、`type`、`path`，按实际情况补充版本、状态、格式和说明；HTML 可声明 `format: 'html'`，正文文档可使用 Markdown。
- 文件目录和分享链接在迭代时保持稳定，历史交给 Git 记录。

站点从 `main` 分支发布到 GitHub Pages。项目资料由对应项目会话上传，UI 更新保留已登记的资料与目录。仓库维持公开。

## 总入口与项目分享页

- `/PM/` 保留项目总聚合页，使用 `assets/portal.*`。
- `/PM/5E/` 与 `/PM/元游猫/` 使用独立的 `assets/project.*`，左侧文档类型、右侧当前类型资料。
- 项目页不提供总览、其他项目或仓库入口；品牌图标不可跳转。分享链接固定在当前项目路径。
- 原有 `?project=5e` 等链接转到对应项目路径，具体功能与资料参数继续保留。
- 这是公开站点的导航范围划分，不是账号权限或保密机制。
- 新增资料仍由对应项目会话登记到 `assets/catalog.js`。调整项目布局不要修改总聚合页模板。
