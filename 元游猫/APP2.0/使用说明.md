# APP2.0 原型查看说明

这份资料对应元游猫 APP2.0 A 方案全链路产品原型 v1.4。

## 如何查看

1. 在资料列表中点击“打开”，原型会在新标签页显示。
2. 页面顶部可切换 C 端 App、运营后台与原型小馆。
3. 使用原型中的页面入口查看交互与规则说明。
4. 需要离线查看时，点击资料右侧的下载按钮，保存 HTML 后用浏览器打开。

## 演示范围

- 原型用于沟通页面结构、交互和业务流程。
- 页面中的价格、商品与状态用于演示，不代表线上实时数据。
- 原型中的登录、购买等交互不等同于真实业务操作。
- 部分图标依赖在线样式资源，离线或网络受限时可能无法显示。
