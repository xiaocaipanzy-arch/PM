APP2.0 原型小馆

集中查看可配置游戏模板、状态组合和首页编排。模板只决定内容表达，不改变真实价格、库存和交易资格。

8 种受控模板 · 演示数据
LANDSCAPE SHELF

横向图文货架

适合时下热门和低价好游，快速比较封面、标签与当前价格。

内容量5–10 项必需内容封面 / 价格
不足 5 项：切换紧凑卡或隐藏主题。
POSTER RAIL

竖版海报横滑

适合编辑精选、系列专题和多人开黑片单。

内容量3–8 项必需内容海报 / 理由
不足 3 项：使用单主题大卡。
DOUBLE COLUMN

双列商品货架

适合超值特卖和价格带专题，提高有限空间内的商品密度。

内容量4–12 项必需内容价格 / 可售
不足 4 项：切换横向货架。
HERO + GRID

主推加网格

一个重点游戏带四个补充选择，适合档期主推。

内容量5 项必需内容主视觉 / 4 商品
不足 5 项：只展示主推大卡。
COMPACT RANK

紧凑热销排行

真实支付样本充足时展示排名、趋势和当前最低价。

内容量5–20 项样本门槛至少 5 款
少于 5 款：改名“大家都在看”。
RELEASE TIMELINE

发售时间轴

只展示明确发售日的游戏，未开售内容不展示价格和购买按钮。

内容量3–8 项必需内容日期 / 封面
页面未交付前，不允许快捷入口上线。
PRICE BAND

价格带榜单

按 50 元以下等预算主题组织真实可售游戏。

内容量5–10 项必需内容价格 / 版本
价格失效：移除并补位。
EDITORIAL

编辑专题大卡

用原创理由解释“为什么值得买”，最终仍回到游戏详情。

内容量1–3 项必需内容理由 / 目标
目标失效：隐藏购买文案或整个主题。

状态组合

原型评审必须同时检查这些状态，不能只看正常供给。

正常供给

真实价格、库存、榜单和三个游戏主题完整展示。

审核隐藏

只隐藏 CS；秒杀过滤 CS 商品，平台产出榜同步隐藏。

供给不足

不显示旧价格，余额改为“查看当前在售”，商品自动补位。

样本不足

游戏热销少于 5 款时改名“大家都在看”，GMV看板只观察。

首页编排预设

预设只改变原型配置，方便评审不同 GMV 策略下的页面组合。
